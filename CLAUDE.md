# FreeWrite — памятка для Claude

Самостоятельный проект, репозиторий `Shulya72/FreeWrite` (с 07.11.2026; до этого жил в рабочей
ветке репозитория сайта `Shulya72/bar-menu`, история перенесена). **С сайтом VIA Bar не связан** —
Владимир просил держать проекты раздельно. Общение с Владимиром — по-русски, просто, без жаргона;
репозиторий публичный — никаких ключей и паролей в коммитах, логах и выпусках.

## Что это

Android-приложение для Huawei MatePad Mini (MLR-W09, HarmonyOS 4.3, 12 ГБ, перо M-Pencil Pro
MAL-CD56). Пишешь пером в любом месте поля, распознанный текст идёт подряд в документ сверху.
Ориентир — рукописный ввод Samsung Notes. Полное ТЗ Владимир прислал в чат 07.11.2026;
краткое изложение и ответы на вопросы — `docs/ИССЛЕДОВАНИЕ.md`.

## Правила работы (из ТЗ, раздел 12)

- Пошаговые инструкции. Владимир не пишет код сам.
- Только целые файлы и готовый APK после каждого этапа. Никаких «вставьте фрагмент».
- **Не переходить к следующему этапу, пока предыдущий не проверен на реальном планшете.**
- Ошибки разбирать по логам и отчёту приложения, не менять наугад.
- Архитектуру не менять без объяснения.
- Главный приоритет — качество распознавания русского почерка, а не внешний вид.

## Где лежит и как собирается

- Код — в корне репозитория (Gradle-проект). Основная ветка `main`; каждый push в `main`
  собирает APK.
- Облачная среда «Приложение Для Рукописного Ввода»: разрешены `dl.google.com` и
  `developers.google.com`. Android SDK — `/root/android-sdk` (cmdline-tools, `platforms;android-35`,
  `build-tools;35.0.0`), сборка `./gradlew assembleDebug` (~30 с), `local.properties` с `sdk.dir`
  не коммитится. Maven Central иногда отвечает 429 — повторить.
- Эмулятора Android в облачной среде нет (нет KVM). Экраны проверяются Robolectric-тестами
  (`app/src/test/.../ScreensSmokeTest.kt`, скриншоты в `app/build/screenshots/`). ML Kit в Robolectric
  не работает (VerifyError, нет `libdigitalink.so` для обычной Java) — ошибка ML Kit на скриншотах
  и «нераспознанная надпись → рисунок» в тестах ожидаемы.
- Сборка — GitHub Actions «Build APK» (`.github/workflows/build.yml`): push в `main` или вручную.
  Шаги: ключ подписи из кэша → `assembleDebug` → Robolectric (`continue-on-error`, смотреть
  PASSED/FAILED в журнале) → выпуск `latest` (APK, `FreeWrite-x.y.z.apk`, `version.txt`, скриншоты).
  Постоянная ссылка: https://github.com/Shulya72/FreeWrite/releases/download/latest/FreeWrite.apk
- Обновление внутри приложения (`Updater`): номер версии — `version.txt` из выпуска на github.com
  (тот же адрес, что у браузера; у Владимира api.github.com был недоступен), запасной путь — API,
  при ошибке — «Скачать в браузере».
- Ключ подписи `freewrite-debug.keystore` создаётся в сборке (keytool, пароли отладочные) и живёт
  в кэше Actions (`freewrite-debug-keystore-v1`), в репозиторий не попадает. Кэш удаляется, если к
  нему не обращаться 7 дней, поэтому раз в неделю задание `keep-signing-key` его трогает (cron;
  GitHub отключает расписание после 60 дней без активности в репозитории). Если ключ всё же
  сменится — обновление встанет только после удаления старой версии (записи пропадут).
  Надёжнее — ключ в секрете репозитория (сделать, когда появятся важные записи).
- Импорты ML Kit 19.0.0: `com.google.mlkit.vision.digitalink.recognition.*` (`Ink`, `Ink.Stroke`,
  `Ink.Point`, распознаватель, модель), результаты — в `...digitalink.common`.
- **Версия:** при каждой сборке для планшета повышать `versionCode` и `versionName`
  в `app/build.gradle.kts`.

## Устройство кода (этап 1)

- Kotlin, без AndroidX и Compose: обычные `View`. AGP 8.10.1, Kotlin 2.1.21, Gradle 8.14.3,
  compileSdk 35, targetSdk 34, minSdk 26.
- `InkCanvasView` — поле для письма (MotionEvent, перо/палец/ладонь, история точек,
  `requestUnbufferedDispatch`).
- `StylusStats` — какие данные о пере доходят (тип, нажим, наклон, наведение, частота).
- `HandwritingEngine` — ML Kit Digital Ink 19.0.0: модели `ru` и `en-US`, загрузка,
  распознавание, номера запросов (старые ответы отбрасываются).
- `DeviceInfo` — сведения для отчёта (HarmonyOS через `hw_sc.build.platform.version`,
  сервисы Google/HMS, экран, сеть, устройства-стилусы).
- `FreeWriteApp` — сохраняет текст падения в `last_crash.txt`, он попадает в следующий отчёт.
- `MainActivity` — экран этапа 1 и «Отправить / Скопировать отчёт».

- **07.11.2026 — 0.5.0: фигуры и правка картинок** (просьба Владимира: «картинка не редактируется»,
  «нарисовал стрелку — превратилась в стрелку, квадрат в квадрат»).
  - `ShapeRecognizer` — чистая геометрия (без ML Kit и интернета): открытый штрих — линия
    (почти горизонтальная/вертикальная выравнивается) или стрелка (самый длинный прямой участок +
    усики по обе стороны у одного конца, ≤55°, ≤½ древка; всё прочее в рисунке должно быть
    наконечником); замкнутый — овал (главные оси) или многоугольник (Douglas–Peucker, 3–6 углов),
    выбирается меньшая ошибка; 4 прямых угла — прямоугольник/квадрат, «на углу» или углы у середин
    сторон рамки — ромб. Несколько штрихов: стрелка (1–3) или сцепка концов в замкнутую фигуру (2–4).
    Результат — ломаная с точками через 4 dp (ластик цепляет) → обычный `Drawing` «pen» с нажимом 0,5.
    Тесты: `ShapeRecognizerTest` (дрожащие фигуры, перехлёст, буквы/знаки/слитное письмо → null);
    перебор по 30 вариантов дрожи — 268/270 фигур узнаны, слитное письмо 0/300.
  - `ShapeTool` — инструмент «Фигуры» (лист и доска): штрих сразу заменяется фигурой; штрихи без
    паузы > 2,5 с собираются с последними 1–3 (древко + наконечник = стрелка, 3 линии = треугольник).
    В «В текст» `ShapeTool.fromWriting`: 1–3 штриха, крупнее 2,6 строки (лист) / 150 dp на экране
    (доска), распознанный текст ≤ 2 букв → фигура вместо текста.
  - Картинки на доске: `BoardView.selected`, касание пальцем — выбрать, уголки (перо или палец,
    любой инструмент) — размер от противоположного угла, палец по выбранной — двигать, два пальца —
    масштаб (`PINCH_IMAGE`); отмена — один шаг на жест (`onDragStart` при первом движении).
    Панель «Удалить / Готово» (`image_bar`). Новая картинка вставляется уже выбранной.
  - Картинки в записи: `Block.Image.wf` (ширина в долях текста, 0 — как раньше) и `xa` (0…1 по
    горизонтали) в JSON. `NoteImageView` — свой вид: уголки — размер, тянуть — вбок (xa) и по
    вертикали (translationY → при отпускании новое место между блоками). Вид шире текста на 14 dp
    (отрицательные поля, `RuledSheet.clipToPadding = false`), чтобы уголки у края не обрезались.
    Пока тянут картинку, перерисовка листа откладывается (`imageEditing`/`renderPending`).
