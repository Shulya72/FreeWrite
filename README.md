# FreeWrite

Приложение для Huawei MatePad Mini: ежедневник, в котором пишете пером в любом месте листа,
а рукопись сама превращается в печатный текст. Ориентир — рукописный ввод Samsung Notes.

- Исследование и результаты проверки планшета — [docs/ИССЛЕДОВАНИЕ.md](docs/ИССЛЕДОВАНИЕ.md)
- Концепция и план этапов — [docs/КОНЦЕПЦИЯ.md](docs/КОНЦЕПЦИЯ.md)
- Интерактивный макет — [design/maket-v1.html](design/maket-v1.html)

## Скачать и обновить

**FreeWrite.apk** — постоянная ссылка на последнюю сборку (открывать на планшете):

https://github.com/Shulya72/FreeWrite/releases/download/latest/FreeWrite.apk

Обновляться можно из самого приложения: на главном экране появляется плашка
«Доступна новая версия» → **«Обновить»** → **«Установить»**. В первый раз Android попросит
разрешить FreeWrite устанавливать приложения: включите переключатель, вернитесь кнопкой
«Назад» и снова нажмите «Установить». Кнопка «Обновления» внизу главного экрана проверяет
вручную. Если проверка не дотянется до сервера, приложение предложит **«Скачать в браузере»**.

Первая установка — по ссылке выше: скачать в браузере, открыть файл, при «Чистом режиме»
выбрать «Разрешить однократно».

> **Переезд 07.11.2026 (версия 0.4.0).** Проект переехал в отдельный репозиторий, сборки
> подписаны новым ключом. Один раз удалите старую FreeWrite (0.3.x и раньше) и поставьте новую
> по ссылке выше. Дальше обновления снова ставятся поверх.

## Как пользоваться

**Ежедневник** (главный экран): дата, «Новая запись», «Новая доска» (сразу спрашивают название),
записи по дням со счётчиками «сдано / не сдано». Нажать на запись — открыть, подержать — переименовать
или удалить.

**Цвета** (в записи и на доске): три последних цвета — кружки на панели; «Цвет» — палитра из 24 цветов
и **«Пипетка»**: коснитесь пером или пальцем надписи, рисунка или фото — цвет станет таким же
(при наведении пера в кружке виден цвет под ним).

**Запись:**

| Что сделать | Как |
|---|---|
| Писать текстом | Инструмент «В текст» (включён сразу). Пишите пером в любом месте листа. Слово серым появляется у оранжевого курсора, через секунду становится текстом, рукопись исчезает. Новое слово можно писать в другом месте — оно встанет следом |
| Рисовать | «Ручка» или «Маркер», цвет — кружки или «Цвет». Рисунок остаётся рисунком |
| Ровные фигуры | «Фигуры»: нарисуйте линию, стрелку, прямоугольник, квадрат, круг, овал, треугольник или ромб — сразу станет ровной фигурой. Стрелка может быть дугой или волной — станет плавной, наконечник — ровным по направлению линии. Стрелку можно рисовать в 2–3 штриха (древко, потом наконечник), прямоугольник — частями, если концы сходятся. Непохожее остаётся как нарисовано |
| Стрелка или рамка при письме | В «В текст» крупная стрелка, рамка или круг (больше 2–3 строк) тоже становятся ровной фигурой, а не буквой |
| Стереть рисунок | «Ластик» — провести пером по рисунку |
| Листать, ставить курсор | Пальцем. Нажмите на место в строке — курсор встанет туда (в т. ч. внутрь слова). Нажатие на пустой лист ниже текста — курсор в конец |
| Стереть букву | Мини-панель → «буква»: одно нажатие — одна буква перед курсором; держать — стирает подряд |
| Исправить букву внутри слова | Пальцем нажмите сразу после неправильной буквы → «буква» → напишите пером правильную: она встанет на место без пробелов |
| Пробел, стереть слово, новая строка, задача | Мини-панель справа сверху. «Строка» посреди текста переносит его остаток на новую строку |
| Исправить слово с клавиатуры | Мини-панель → «править» |
| Отметить задачу «сдано» | Нажать на квадратик или на «не сдано» — пальцем или пером |
| Вставить картинку | «Картинка» → выбрать из галереи |
| Размер и место картинки | Коснитесь картинки пальцем — появится рамка с уголками. Тянуть за уголок — размер (пропорции сохраняются), за саму картинку — сдвинуть вбок или перенести выше/ниже по тексту. «Готово» — снять выбор, «Удалить» — убрать (или подержать картинку) |
| Отменить / вернуть | «Отменить», «Вернуть». Недописанное слово отменяется по одному штриху |
| Итоги | «Итоги» — что сдано и что нет, можно скопировать. ИИ-помощник будет позже |
| Писать пальцем | Флажок «Палец пишет» (для проверки без пера) |

Записи сохраняются сами. Если надпись не удалось распознать, она не пропадает, а остаётся рисунком.

**Доска** (с версии 0.3.0) — бесконечное поле:

| Что сделать | Как |
|---|---|
| Двигать и масштабировать | Одним пальцем — двигать, двумя — приблизить/отдалить. «Всё» — показать доску целиком |
| Писать текстом | «В текст»: надпись пером становится печатным текстом на том же месте |
| Рисовать, стереть | «Ручка», «Маркер», цвета; «Ластик» стирает рисунки, надписи и метки |
| Ровные фигуры | «Фигуры» — как в записи: линия, стрелка (и дугой), прямоугольник, круг, треугольник, ромб. Крупная стрелка или рамка в «В текст» — тоже фигура |
| Свои статусы | «Статусы»: список доски — «+ Добавить статус» (название и цвет), ✎ — изменить, ▲▼ — порядок, ✕ — удалить. Порядок списка — порядок переключения касанием. Рядом — сколько меток и выносок с каждым статусом |
| Метки статуса | «Метка»: коснитесь пером — появится метка с первым статусом. Касание метки пальцем — следующий статус по списку, подержать — выбрать из списка |
| Мультивыноска | «Выноска»: проведите пером от места на чертеже туда, где будет надпись, — откроется окно: надпись («Захватка №1 от 11.09.26») и статус. Нижняя строка выноски — кнопка статуса: касание — следующий статус («Сдали опалубку» → «Забетонировано» → …), подержать — список. Ещё указатель — провести пером от рамки к месту (или «+ Указатель»). Концы указателей выделенной выноски можно тянуть; конец, утащенный на рамку, убирает указатель |
| Заливка (захватки) | «Заливка»: обведите пером стену или захватку — она зальётся выбранным цветом, полупрозрачно, чертёж под заливкой виден. Прямоугольник и многоугольник выравниваются. Замкнутую фигуру можно залить кнопкой «Залить» на панели выделенного. Стереть — ластиком по краю заливки |
| Картинка | «Картинка» → из галереи, можно выбрать сразу несколько: лягут рядами в середине экрана, уже выделенными |
| Выделить один объект | Коснитесь пальцем надписи, рисунка, стрелки, фигуры или картинки — рамка с уголками |
| Выделить несколько | Инструмент «Выделить»: обведите пером или пальцем (лассо). Касание — один объект. Доску в этом инструменте двигают двумя пальцами |
| Править выделенное | Тянуть — передвинуть; уголок или два пальца на выделенном — больше/меньше. Панель сверху: «Изменить» (текст надписи), «Копия» (текст надписи ещё и копируется), «Цвет» (палитра или пипетка), «Удалить», «Готово» |
| Отменить / вернуть | «Отменить», «Вернуть» |

Доски сохраняются сами и видны в Ежедневнике со счётчиками по статусам.

**Большие доски** (с версии 0.8.0): сотни чертежей и тысячи надписей не тормозят — рисуется только то,
что на экране, картинки грузятся в нужном размере в фоне, при сильном приближении чертёж остаётся чётким
(хранится оригинал до 8192 px). Подержать надпись масштаба внизу слева — показать, сколько миллисекунд
рисуется кадр. Тестовая доска для проверки — «Проверка планшета» → «6. Скорость доски».

Перед первой записью приложение попросит скачать русскую модель распознавания (≈20 МБ, один раз;
дальше работает без интернета).

**Проверка планшета** (внизу главного экрана) — экран этапа 1: модели, данные о пере,
кнопки «Отправить отчёт» и «Скопировать отчёт». Если что-то работает не так — пришлите отчёт.

## Для разработчика

- Проект — Gradle, Kotlin, AGP 8.10, ML Kit Digital Ink 19.0.0.
- Сборка в облаке: GitHub Actions «Build APK» (`.github/workflows/build.yml`) — при каждом изменении
  ветки `main`; APK, номер версии и скриншоты экранов → выпуск `latest`.
- Локально: `./gradlew assembleDebug` (JDK 17+, Android SDK), проверка экранов —
  `./gradlew testDebugUnitTest` (Robolectric, скриншоты в `app/build/screenshots/`;
  `ShapeRecognizerTest` — фигуры «от руки» и буквы, которые фигурами стать не должны).

| Файл | Что делает |
|---|---|
| `HomeActivity.kt` | Ежедневник: записи и доски по дням, обновление |
| `BoardImages.kt` | Картинки доски: оригинал + копии 256/1024/2048, фоновая загрузка, память, чёткий кусок при приближении |
| `TestBoard.kt` | Тестовая доска для проверки скорости |
| `BoardActivity.kt`, `BoardView.kt`, `Board.kt` | Доска: камера, перо/палец/щипок, текст на месте, метки, картинки, хранение |
| `InkPainter.kt` | Общее рисование штрихов (лист и доска) |
| `ColorKit.kt` | Палитра из 24 цветов, последние цвета, пипетка (снимок экрана + цвет объекта) |
| `ShapeRecognizer.kt` | Распознавание фигур — чистая геометрия, без интернета (линия, стрелка, прямоугольник, круг…) |
| `ShapeTool.kt` | Инструмент «Фигуры»: штрих → ровная фигура, несколько штрихов подряд → стрелка/многоугольник |
| `NoteActivity.kt` | Запись: лист, инструменты, письмо в текст (группы штрихов, очередь вставки без дублей) |
| `NoteViews.kt` | `RuledSheet` (лист с линовкой), `NoteInkView` (слой пера: перо пишет, палец уходит листу), `NoteImageView` (картинка: выбор, уголки, перенос) |
| `Note.kt` | Модель записи, JSON, хранение в файлах, картинки |
| `HandwritingEngine.kt` | ML Kit: модели, загрузка, распознавание |
| `Updater.kt` | Проверка выпуска на GitHub, скачивание, установка |
| `DiagnosticsActivity.kt` | Проверка планшета (этап 1) и отчёт |
| `Ui.kt` | Цвета и элементы интерфейса по макету |
