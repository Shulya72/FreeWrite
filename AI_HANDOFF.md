## Известные проблемы / риски (FW-003)

- База YDB ограничена 10 RU/с: первая загрузка большой доски (11 тыс. предметов) на сайте может идти дольше (сайт
  повторяет запросы, когда сервер «занят»); дальше — из кэша браузера и только новые правки.
- Картинки идут через функцию частями (как у приложения) — первая загрузка листов-чертежей медленнее, потом из кэша.
- Ссылка «Открыть на компьютере» содержит код доски (с правом правки в приложении) — она для себя; руководству —
  «Ссылка для руководства» на сайте.
- Сайт только смотрит, править с компьютера нельзя (по ТЗ — просмотр).

## Известные проблемы / риски (FW-011)

- Подписи «Чек-лист», «DWG», «ИГС» в строке — постоянные; если нужны свои — следующая доработка.
