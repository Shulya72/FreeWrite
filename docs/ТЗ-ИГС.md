## 0. Зачем

Сейчас геодезист пишет одно и то же в нескольких местах: у чертежа (захватки, наличие схем), в списках «что отдал на
подпись / что вернули», потом сводит всё в Excel. Через несколько дней записи расходятся и непонятно, что сдано, а что нет.

**Главный принцип:** каждая схема ИГС хранится **в одном месте**. Таблица у чертежа, ведомость передачи, подсветка
захватки на плане, сводка — только разные «окна» на одни и те же записи. Поменяли статус в одном окне — он поменялся
везде. Ничего не переписывается вручную дважды.

## 1. Что уже есть и не ломается

- Рукописный ввод (Запись, «В текст» на доске), доска: картинки и листы PDF, заливки, разделы, метки, выноски, фигуры,
  импорт из Nebo — всё остаётся как есть.
- Общая доска на сервере в Яндекс Облаке (бесплатные лимиты), правки расходятся за несколько секунд; код на правку и
  код «только смотреть»; сайт для просмотра с компьютера.
- Статусы конструкций (выноски) остаются. Список статусов ИД заменяется новым списком ИГС (раздел 4).
- Старые «строки ИД» (0.18) переносятся в новые таблицы кнопкой «В таблицу» — ничего не теряется.

## 2. Основные понятия

| Понятие | Что это | Как выглядит |
|---|---|---|
| **Объект** | Одна доска = один строительный объект | Доска в Ежедневнике |
| **Раздел** | **Шифр проекта** («КЖ 6.1.1», «КЖ 7.2.2») — 0.21, решение Владимира | Рамка раздела на доске (уже есть) |
| **Таблица ИД** | Подраздел шифра со своей нумерацией захваток и своими объёмами: «Несущие стены», «Ненесущие стены»; «Основная плита», «Технический канал». Один подраздел на весь шифр — таблица называется шифром | Таблица внутри раздела, рядом с план-схемой |
| **Схема** | Одна исполнительная схема = одна строка таблицы | Строка: захватка/участок, конструкция, вид работ, статусы, даты |
| **Ведомость** | Пачка схем, которую отдают АН, заказчику или в ПТО | Отдельная табличка в любом месте доски |
| **Захватка на плане** | Закрашенная область на план-схеме, привязанная к захватке таблицы | Заливка (уже есть) |
| **История** | Кто, когда и что поменял у схемы | Окно «История» у строки |

**Одна строка = одна схема.** Если на одну работу нужно несколько схем — работа дробится на захватки или участки
(как сейчас в Excel). Признак «та же схема»: таблица (шифр) + захватка/участок + конструкция + вид работ;
повтор в одной таблице — предупреждение.

## 3. Таблица ИД

### 3.1. Вид
- Шапка: **шифр** (крупно) и сводка в одну строку: «54 схемы · сдано в ПТО 39».
- Строка с названиями столбцов, ниже строки схем. **Все строки одного размера и ровно по столбцам**; ширина столбца — по
  самому длинному значению. Размер задаётся один на всю таблицу; новая таблица — того же размера, что уже стоящие на доске.
- Таблица двигается и масштабируется целиком (как картинка), переносится вместе со своим разделом.
- Издалека — рамка и цветные полоски статуса ИГС (видно, где «горит», без надписей).

### 3.2. Столбцы — настраиваемые
По умолчанию (0.22.1, порядок от Владимира: № АОСР, № схемы, участок, захватка, тип конструкции, вид работ, объём, дата и далее).
Шифр — это раздел (рамка) и шапка таблицы: «КЖ8 · Лестничные марши»; в ведомостях, Excel и сводке он — отдельный столбец «Шифр».

| Столбец | Что | Ввод |
|---|---|---|
| Участок | Часть шифра со своей нумерацией захваток (0.22.1, Владимир): лестницы КЖ8 — «LM1», «LM2», «LM3». Можно не заполнять | Текст; «+ следующая захватка» берёт участок последней строки |
| Захватка | Номер захватки: «5», «5.1», «3 этаж», «Захватка №1 (6-7/А-Е)», «Лоток №1», «19-21/А». «3 этаж» участка LM1 и «3 этаж» участка LM2 — разные захватки | Текст |
| Тип конструкции | «Вертикал», «Парапет», «Плита пола Пм1», «Марш», «Площадка межэтажная» (до 0.22.1 — «Конструкция») | Текст с подсказками из уже введённого |
| Вид работ | «Опалубка», «Бетон», «Разработка», «Обратная засыпка», «Кладка», «Монтаж»… | Выбор из списка или текст |
| № АОСР | Номер акта освидетельствования скрытых работ — 0.21, просьба Владимира (сначала АОСР, потом схема) | Текст; подсказка — следующий номер после последнего в таблице |
| № схемы | Номер исполнительной схемы («ИС-12») — 0.21 | Текст; подсказка — следующий номер |
| Объём по схеме | Объём из исполнительной схемы (0.21); единица — по виду работ: бетон, грунт, кладка — м³, опалубка — м², армирование — т, монтаж — шт | Число: цифрами или пером в ячейку |
| Дата работ | Дата бетонирования / выполнения работ | Календарь |
| Чек-лист | Статус чек-листа (раздел 4.2) | Касание — список |
| DWG | Статус DWG (раздел 4.3) | Касание — список |
| ИГС | Статус схемы (раздел 4.1) | Касание — список |
| Отдал заказчику | Дата, когда схему отдали заказчику на подпись | Ставится ведомостью, можно поправить |
| Сдано в ПТО | Дата, когда схему сдали в ПТО | Ставится ведомостью, можно поправить |
| Исполнитель | Подрядчик: «АР-Старт», «СТЭП», «МС22», «СС» | Текст с подсказками |
| Примечание | Любой текст: «вопрос у ПТО по объёму (9.1)» | Текст |

Настройка таблицы:
- переименовать столбец (например, «Захватка» → «Этаж»);
- скрыть / показать столбец;
- добавить свой текстовый столбец (для другого объекта: «Секция», «Этаж», «Оси»);
- взять столбцы «как у таблицы …» (чтобы не настраивать каждую заново).

### 3.2а. Объёмы (0.21, по просьбе Владимира)
- Внизу таблицы — блок **«Объёмы»**: по каждому виду работ — сколько схем с объёмом, **факт** (сумма столбца «Объём по схеме»),
  **проект** (рамка ✎ — вписывается один раз на таблицу и вид работ, с единицей), разница: синим «осталось …», красным
  «перебор +… · +… %» (допуска нет — любое превышение красным), полоска и процент выполнения. «+ проект» — вид работ, которого ещё нет.
- Схемы без объёма в факт не входят — строка «Объём не указан у N схем», касание показывает их.
- **Всего по шифру** (раздел) — в «Сводке ИГС» по разделу, в Excel и на сайте: сумма таблиц раздела. Если проект вписан не у всех
  таблиц раздела — «проект вписан не у всех таблиц» (процент не считается, чтобы не обмануть).
- Новая таблица в разделе спрашивает только название подраздела; шифр — у раздела (в шапке мелко «КЖ 6.1.1 ·»). В Excel, ведомостях,
  сводке таблица называется полностью: «КЖ 6.1.1 · Несущие стены».

### 3.2б. Виды таблиц (0.24, Владимир 13.11.2026)
- Кнопка **«Таблица ИД»** открывает окно-проводник «Таблица ИД — какую ставим?»: поиск, разделы с плюсиком (пока только **КЖ** —
  «Конструкции железобетонные»; остальные разделы добавим по ходу), в раскрытой ветке — виды таблиц с подсказкой, на какие части
  делится объём и какие работы по умолчанию. Внизу — «Пустая таблица — как сейчас, без вида» (один объём, своё название).
- Выбрали вид — таблица встаёт в раздел, где вы на доске (в видимой части, не поверх других таблиц), называется по виду
  («КЖ 6.1.1 · Вертикальные элементы»), сразу открывается «+ строка». Вне разделов — спрашивается шифр. Пока выбрана «Таблица ИД»,
  касание доски — проводник и таблица на этом месте.

| Вид | «Объём по схеме» делится на | Работы по умолчанию | Скрыт по умолчанию |
|---|---|---|---|
| Вертикальные элементы | Стены · Колонны | Опалубка, Бетон (без армирования) | Тип конструкции |
| Плиты перекрытия | Плита · Балки | Опалубка, Бетон (без армирования) | Тип конструкции |

- Шапка таблицы в два этажа: «Объём по схеме» над «Стены | Колонны»; у названия — плашка вида «вид: КЖ · вертикальные элементы».
- Касание ячейки части — сразу число (как у объёма в 0.23.1), перо «В текст» — тоже пишет в неё. История: «Объём · Стены: 186,4 → 186,9».
- Итоги внизу — сеткой: строки — виды работ, столбцы — части и «Всего» (сумма частей). В ячейке: факт, **проект этой части**
  (рамка ✎ — касание вписать), полоска, «осталось …» / «перебор …», процент. «+ проект» — спросит вид работ и часть.
- Сводка, Excel и сайт — по частям: «Несущие стены · опалубка · стены»; в Excel столбцы «Объём · Стены», «Объём · Колонны»…
  числом и «Ед.».
- **Таблицы до 0.24** (Владимир: «старые таблицы переведи в стены, объёмы обнули, я протыкаю их снова») считаются
  «Вертикальными элементами»: вместо «Объёма по схеме» — Стены и Колонны (пустые), прежний объём и проект не считаются.
  Данные доски при этом не переписываются (вид у старой таблицы не записан — так и понимается) — поэтому планшет коллеги со
  старой копией доски не затрёт вписанные заново объёмы. Свой список столбцов старой таблицы записывается с частями при первой
  правке столбцов.

### 3.3. Заполнение
- **Касание любой ячейки — сразу её ввод, без карточки строки** (0.25.1, Владимир: «чтоб быстрее»): текст — поле с
  подсказками, дата — календарь, объём — число, статус — список у ячейки. На клавиатуре «Далее» — сохранить и сразу открыть
  следующую ячейку этой строки (статусы пропускаются). У номера захватки цветной квадратик — план/заливка (как раньше), сам
  номер — ввод. Карточка строки — подержать строку → «Карточка строки».
- Статус (Чек-лист, DWG, ИГС): касание самого статуса (пальцем или пером) → короткий список рядом с ячейкой → выбор
  (0.20.1: без карточки — быстро; случайное касание только открывает список).
- Текст: касание ячейки → поле с подсказками (что уже встречается в этом столбце) и кнопками частых значений;
  писать можно **пером** (распознавание, как «В текст») или клавиатурой.
- Дата: календарь, кнопка «Сегодня», «Без даты».
- «+ строка» внизу таблицы — форма всей строки сразу; в ней кнопки видов работ можно отметить несколько
  («Опалубка» + «Бетон») — появится по строке на каждый.
- «+ Следующая захватка» — номер +1, конструкция и исполнитель как у предыдущей, статусы — начальные.
- Подержать строку — меню: изменить строку, история, строка ниже, вверх/вниз, в ведомость, удалить.
- «Конструкция не выполнена» — одной кнопкой: Чек-лист, DWG и ИГС = «Не выполнено».
- Отбор и поиск: показать в таблице только строки со статусом / исполнителем / текстом (остальное скрыто до «Показать всё»).

## 4. Статусы

Порядок работы: сначала сдаём конструкцию и готовим чек-лист; когда чек-лист подписан — готовим схему.
Названия и цвета можно поправить в «Статусах»; ниже — начальные списки (от Владимира).

### 4.1. ИГС (схема)

| Статус | Смысл | Цвет |
|---|---|---|
| Конструкция не выполнена | Конструкция не возведена (название — по просьбе Владимира 11.11.2026) | серый |
| Не предоставлена | Не понимаем, что со схемой | красный |
| В работе | Схема делается | синий |
| Сборка | Схема готова и лежит в пачке ведомости на столе (0.22.1, Владимир) | бирюзовый |
| На согласовании АН | Нужно согласование авторского надзора (отклонения сверх допуска) | фиолетовый |
| Не согласована | АН не согласовал отклонения — нужно решение | тёмно-красный |
| На подписи у заказчика | Унесли на подпись | жёлтый |
| Возврат на корректировку | Заказчик или АН выявили замечания | оранжевый |
| Сдано в ПТО | Схему отдали в ПТО — **это и есть «сдано»** | зелёный |

### 4.2. Чек-лист

| Статус | Смысл | Цвет |
|---|---|---|
| Не выполнено | Конструкция не выполнена | серый |
| Не предъявлено | Конструкция возведена, но её не предъявили | красный |
| Нет возможности предъявить | Конструкцию загромоздили — освидетельствовать нельзя | оранжевый |
| Предъявлено | Есть чек-лист, подписанный заказчиком | зелёный |

### 4.3. DWG

| Статус | Цвет |
|---|---|
| Не выполнено | серый |
| Нет | красный |
| Есть | зелёный |

### 4.4. Подсказки (не запреты)
- Схема «В работе» или дальше, а чек-лист не «Предъявлено» — строка помечается, попадает в «Контроль» (раздел 9).
- Файлы (DWG, PDF, сканы) в приложение **не загружаются** — только статусы (не грузим сервер).

## 5. Даты по схеме
- **Дата работ** — вводится вручную.
- **Отдал заказчику** — ставится сама при передаче ведомости заказчику (дата передачи) или при «Согласовано» от АН
  (после согласования АН схему сразу несут заказчику), можно поправить вручную.
- **Сдано в ПТО** — ставится сама, когда заказчик вернул схему подписанной (подписанную сразу отдают в ПТО) или при
  сдаче ведомостью в ПТО, можно поправить вручную.
- Остальные даты (передал АН, вернули с замечаниями) видны в истории схемы и в ведомостях.

## 6. Ведомости

### 6.1. Виды

| Вид | При передаче схемам ставится | Результаты по каждой схеме |
|---|---|---|
| На согласование АН | ИГС «На согласовании АН» | «Согласовано» → «На подписи у заказчика» + дата «Отдал заказчику», в истории «согласовано АН, дата» · «Не согласовано» → «Не согласована» · «Замечания» → «Возврат на корректировку» |
| На подпись заказчику | ИГС «На подписи у заказчика», дата «Отдал заказчику» | «Подписано» → сразу «Сдано в ПТО» + дата «Сдано в ПТО» · «Замечания» → «Возврат на корректировку» |
| Сдача в ПТО | ИГС «Сдано в ПТО», дата «Сдано в ПТО» | — (закрывается сразу; для схем, которые отдают в ПТО отдельно) |
| Список | Ничего (просто список: «что делать завтра», «что проверить») | — |

Согласованные АН схемы приложение предлагает одной кнопкой собрать в ведомость «На подпись заказчику» — чтобы ответы
заказчика отмечать уже в ней.

### 6.2. Как живёт ведомость
1. **Сборка** (0.22.1, Владимир; было «черновик»). Создали ведомость в любом месте доски («На подпись заказчику», номер ставится
   сам: «З-12»), собрали схемы — они лежат на столе, у схем статус ИГС «Сборка» (если были «В работе», «Не предоставлена»,
   «Возврат», «Не согласована»). Убрали схему из сборки или удалили ведомость — у схемы прежний статус.
2. **Унесли** — состояние ведомости «На подписи у заказчика» (для АН — «На согласовании АН», для ПТО — «Сдано в ПТО»): кнопка
   состояния в шапке ведомости («Сборка ▾») или внизу «На подписи у заказчика →» → дата (сегодня, можно поправить) → «Унесли
   заказчику»: всем схемам разом статус и дата. Ошиблись — там же «Сборка» (пока нет ответов).
3. **Ответы по частям.** Заказчик может вернуть часть сегодня, часть завтра, часть послезавтра, часть — с замечаниями.
   Отмечаем результат у одной схемы или у выделенных разом; у каждой позиции своя дата ответа.
   В шапке: «15 схем · подписано 12 · замечания 2 · ждём 1 (6 дней)».
4. **Закрыта** — сама, когда у всех позиций есть результат. Остаётся в архиве (список ведомостей доски) с исходным составом
   и датами, даже если потом статусы схем поменялись.

### 6.3. Как собрать
- Из таблиц: окно отбора — шифр / раздел / статус / исполнитель («все „В работе“ по КЖ 6.1.1») → отметить галочками.
- Выделить строки прямо в таблице ИД → «В ведомость».
- Вписать вручную: шифр + захватка + вид работ (пером или клавиатурой). Есть такая схема — добавляется ссылкой.
  **Нет схемы** — приложение предлагает создать строку в таблице этого шифра (с известными полями, остальное пусто);
  нет и таблицы шифра — предлагает создать таблицу. Без подтверждения ничего не создаётся.
- Схема уже ждёт ответа в другой открытой ведомости — предупреждение.

### 6.4. На доске
Ведомость — табличка: шапка (вид, номер, кому, дата передачи, сводка ответов), строки — шифр, захватка, конструкция,
вид работ, текущий статус ИГС, результат по этой ведомости и его дата. Касание строки — показать схему в её таблице.

Как сделано в 0.21:
- Кнопка **«Ведомости»** на панели доски: «+ Новая ведомость» (вид → номер и кому → встаёт рядом, не поверх таблиц →
  сразу окно сбора) и список: ждут ответа, черновики, списки, закрытые (архив). Касание — доска переезжает к ведомости.
- Номера по виду: «А-1» (АН), «З-1» (заказчик), «П-1» (ПТО), «С-1» (список); можно поправить.
- Внизу черновика: «+ схемы» и «Передать →». Отбор при сборе для АН и заказчика сразу стоит на «В работе» и
  «Возврат на корректировку».
- Ответ: касание ячейки «Ответ» («Ждём») пальцем или пером — список рядом с ячейкой; дата ответа — строкой в этом же списке
  (запоминается, пока не поменяют: удобно отмечать пачку, которую вернули вчера). Обвести строки «Выделить» → «Ответ…» — всем.
  «Ждём ответа» — отменить ответ (статус снова «на подписи»).
- Остальная строка: пальцем — карточка позиции (статус сейчас, ответ крупными кнопками, ▲/▼, «Показать в таблице», «История»,
  «Убрать из ведомости»); пером — сразу схема в таблице, внизу «← К ведомости». Подержать строку — меню.
- Выделенная ведомость: «+ схемы», «Передать», «Ответ всем ждущим», «Согласованные → заказчику», «Изменить», «В Excel», «Все ведомости».
- Удаление ведомости — с подтверждением; статусы, даты и история схем не меняются.

### 6.5. Сборка прямо из таблицы (0.25, Владимир 13.11.2026)
Как работает Владимир: забивает в таблице очередную захватку, ставит ИГС «Сборка» — схема ложится в пачку на столе;
закончил — пачку уносит, и статус должен поменяться у всех схем пачки сразу.
- **Первая «Сборка» за день** (в ячейке, списком, пером, лассо) — окно «Сборка — ведомость от 13.11.2026?»:
  «Создать» / «Не сегодня». Заводится одна ведомость сборки (на подпись заказчику) **от сегодняшнего дня** (дата видна в шапке:
  «Сборка от 13.11.26 ▾»), в неё — все схемы в «Сборке», которых нет в ведомостях.
- **«ИГС сейчас» в ведомости сборки** (Владимир: «2 варианта — Сборка и на согласовании АН; что на АН — прокликаю вручную»):
  касание ячейки — список рядом: «Сборка» (пойдёт заказчику) или «На согласовании АН» (сначала на согласование АН). Статус схемы в
  таблице меняется тоже. То же из таблицы: «Сборка» → «На согласовании АН» у схемы в сборке — она остаётся в ведомости, через АН.
- **Место ведомости выбирает Владимир** (схемы из разных таблиц — ведомость туда, где удобно; «как на компьютере: левой двигаю
  экран, правой — меню «Вставить»»): после «Заказчику» / «На АН» — панель «Ведомость З-14 от 13.11.26: двигайте доску, подержите
  палец или перо там, где поставить» и «Отмена». Палец и перо в этом режиме только двигают доску (два пальца — приближают);
  подержали ~0,5 с — на доске пунктирный контур «Ведомость — сюда» и меню **«Вставить ведомость сюда» / «Не сюда»**.
  Так же ставятся и «+ Новая ведомость», и «Согласованные → заказчику». Отмена — ведомость не создаётся, схемы остаются в «Сборке».
- **Дальше в этот день** «Сборка» в таблице — схема сама ложится в эту ведомость, без вопросов (подсказка «+1 схема · всего 5»).
  «Отменить» убирает и статус, и место в ведомости.
- **Сняли «Сборку»** в таблице (ошиблись, схема не готова) — схема уходит из ведомости на столе.
- «Не сегодня» — до завтра на этой доске не спрашивает. Если сегодняшнюю ведомость уже унесли, новая «Сборка» спросит снова
  (вторая ведомость за день).
- **Унесли:** кнопка состояния в шапке ведомости → «На подписи у заказчика» — сразу, без окна: дата — день перевода. У схем
  в «Сборке» статус **«На подписи у заказчика от 13.11.26»** и дата «Отдал заказчику»; схемы на АН — как были
  («На согласовании АН от …» — день, когда отметили). Кнопка ведомости — «На подписи у заказчика от 13.11.26 ▾». Унесли в другой
  день — там же «выбрать дату».
- **Ответы:** по схеме «через АН» — как у АН («Согласовано» / «Не согласовано» / «Замечания»); «Согласовано» — схема
  «На подписи у заказчика от <дата ответа>» и ждёт подписи заказчика в этой же ведомости. Остальные — «Подписано» / «Замечания».
- Статус с датой виден и в Excel-описи («Ведомость З-14 от 13.11.2026»), и на сайте.

## 7. История
- Каждая правка статуса или даты схемы записывается: **кто** (имя, фамилия), **когда**, **было → стало**, по какой ведомости.
- Окно «История» у строки; история не стирается.
- Правки двух людей в разных строках не мешают друг другу; если двое меняют одну ячейку — остаётся последняя правка,
  обе видны в истории.

## 8. Захватки на плане
- Владимир сам раскрашивает захватки **разными цветами** — для ориентира (как сейчас). Цвет статусом не перекрашивается.
- Заливку один раз **привязывают к захватке** таблицы: выделить заливку → «Захватка» → выбрать таблицу и номер.
  Одна захватка может иметь несколько заливок (на разных листах).
- **Касание заливки → в таблице подсвечиваются строки этой захватки** (опалубка, бетон…), и наоборот:
  **касание номера захватки в таблице → подсвечивается её заливка** на плане (экран переезжает, если она не видна).
- По желанию на заливке пишется номер захватки.

Как сделано в 0.22:
- Выделить заливку (касание пальцем; несколько — «Выделить» лассо) → **«Захватка»** → таблица (если в разделе одна — сразу она;
  «Другая таблица») → номер кнопкой из захваток таблицы (✓ — у захватки уже есть заливка) или вписать → «Номер на заливке» → «Привязать».
  «Отвязать» — там же. Копия заливки сохраняет захватку.
- Касание привязанной заливки — она выделена, строки её захватки в таблице подсвечены, на панели: «Захватка 2 · КЖ 6.1.1 · Несущие
  стены · опалубка — в работе, бетон — …», кнопка **«В таблице»** — доска переезжает к строкам.
- В таблице у номера захватки с заливкой — **значок цвета заливки**. Касание такого номера (пальцем или пером) — заливки захватки
  подсвечены рамкой, доска переезжает к ним, если их не видно; внизу «← К таблице» и «Готово». Номер без заливки — как раньше.
- В карточке строки — «Захватка N на плане». В Excel ячейка захватки — цветом её заливки. На сайте — номера на заливках и значки.
- С участком (0.22.1): в окне «Захватка» кнопки «LM1 · 3 этаж», «LM2 · 3 этаж» и поле участка; на заливке — «LM2 · 3 этаж»;
  подсвечиваются строки только этого участка.

### 8а. План под таблицей (0.23, Владимир 12.11.2026)
«Это пока не упрощает жизнь — давай внутрь таблиц добавление картинки: сверху захватки, а снизу план-схема, на которой
отображаются захватки». Макет согласован; ответы Владимира: переключатель цвета; один план, но «+» — добавить ещё лист;
на областях — только цвет, без надписей; обводку — полуавтоматом (пальцем промахиваешься, круг не нарисовать); обрезка листа
при вставке (на чертеже рамка, разрезы — нужен только план).
- **«+ план»** внизу таблицы (и «+ план» / «План» на панели таблицы) → «Лист PDF» или «Картинка» → **экран обрезки**: рамка с
  ручками, «Весь лист», «Готово — под таблицу». Лист встаёт под таблицей по её ширине и двигается вместе с ней. Позже —
  «План» → «Обрезать», «Название вкладки», «+ ещё лист», «Убрать этот лист». Несколько листов — вкладки.
- **Шапка плана:** «Цвет: по ИГС ▾ / свой ▾», «+ лист», «Обвести захватку» (выбор захватки, ✓ — уже обведена).
- **Обвести захватку** (или касание пальцем номера ещё не обведённой захватки в таблице — у таких номеров пунктирный квадратик):
  - **«Волшебная»** (как Dynamic Fill в Bluebeam Revu): касание внутри помещения/плиты — контур по линиям чертежа; касание по
    колонне/пилону (тёмная или заштрихованная) — сама колонна; можно несколько касаний — несколько кусков.
  - **«Зазор − / +»** — какие щели в линиях закрывать (дверные проёмы, разрывы), чтобы заливка не вытекала; дошла до края
    плана — подсказка «прибавьте зазор».
  - **«▭»** и **«◯»** — протянуть от угла до угла; **«По точкам»** — касания углов, касание первой точки замыкает.
  - «Отменить» — последний кусок/точка (и кнопка «Отменить» доски), «Готово» — куски стали областями захватки, «Отмена».
- **Цвет:** по ИГС — по самой отстающей схеме захватки (зелёная — только когда сданы все её схемы); свой — у каждой захватки.
  Внизу — легенда (сколько захваток в каком статусе). Надписей на областях нет.
- **Касание области** — подсвечены её строки в таблице и сама область; внизу «Захватка 2 · опалубка — Сдано в ПТО, бетон — На
  подписи у заказчика», «Обвести ещё», «Стереть с плана», «Готово». **Касание номера обведённой захватки** — её области (вкладка
  переключается сама). В карточке строки — «Обвести захватку N на плане» / «Захватка N на плане».
- Значок цвета у номера захватки в таблице и цвет ячейки «Захватка» в Excel — по областям плана. Сайт показывает план, области,
  легенду, вкладки (щелчок — другой лист). Заливки, привязанные на доске в 0.22, работают как раньше.
- **0.23.1 (Владимир после проверки 0.23.0):**
  - Рисунки пером поверх плана видны (таблицы теперь под штрихами). Таблицу можно **закрепить булавкой** («Закрепить» на панели
    таблицы; булавка в углу — «Открепить»): не двигается и не меняет размер. Незакреплённая таблица переносится вместе с рисунками
    и надписями на своём плане.
  - «Волшебная»: что под пальцем, решает сама линия — касание рядом с текстом или размерами заливает помещение, а не «прилипает»
    к буквам; по букве — тоже помещение. **Касание стены — стены** (всё соединённое), а не «это стена, а не колонна».
  - **«Кисть по стенам»**: провели вдоль нужных стен — берутся стены под кистью (каждая своим куском); по бумаге — след кисти.
  - **Лупа** с перекрестием и привязкой (к точкам и углам областей) при обводке пальцем «По точкам», «▭», «◯».
  - **«● Цвет»** в панели обводки и у обведённой захватки: палитра 24 цвета, последние, пипетка (цвет области или пикселя
    плана). Выбрали цвет, а у таблицы «по ИГС» — переключается на «свой»; у всей захватки цвет один.
  - **Объём:** касание ячейки «Объём по схеме» (и пальцем) — сразу ввод числа, без карточки строки.
  - **Раздел:** у выделенного раздела 8 ручек — углы и середины сторон; каждая сторона тянется отдельно, содержимое не меняется.

### 8б. Разметка этажа и захватки касанием (0.26, Владимир 13.11.2026)
Владимир: «начинается новый шифр — сразу создаю таблицу, прикрепляю план этажа и штрихую каждый элемент; забетонировали
7 колонн — создаю захватку 1, выбираю её и пальцем проставляю выделенные участки — они окрасились в цвет захватки; внизу —
процент выполнения конструкции». Проверено на его чертежах КЖ 7.1.3 (стены) и КЖ 7.2.2 (плита).
- **PDF листа хранится вместе с картинкой** (лист, вставленный под таблицу из PDF). У листа, вставленного раньше или картинкой,
  «Найти элементы» попросит выбрать тот же PDF ещё раз (картинка листа не меняется).
- **«Элементы ▾»** в шапке плана: «Найти элементы на листе…», «Ножницы / шов», «Добавить элемент вручную», «Убрать элементы
  касанием», «Убрать всю разметку листа». После вставки листа из PDF приложение само предлагает найти элементы.
- **«Найти элементы»** — по линиям чертежа (не по картинке): слои AutoCAD, толщина линий, заливки. Текст, размеры, оси, выноски,
  невидимые линии и проёмы не трогаются. Что искать — выбор (по умолчанию — по таблице):
  - **несущие стены и пилоны** — жирный контур; в проёмах стена замыкается поперёк; «Р.Ш.Б.» — часть пилона;
  - **ненесущие стены** — тонкий контур со штриховкой (Владимир: «одна подложка к двум таблицам — в одной несущие, в другой
    ненесущие»);
  - **плита перекрытия** — по краю (балконы, дуги), минус отверстия и проёмы со значком; швы-зигзаги чертежа режут плиту
    (продлеваются до края — проверить глазами). Балки и утолщения — внутри плиты.
  - **«Слои чертежа…»** — какие слои участвуют (по умолчанию — по названию; выбор запоминается для доски).
  - Найденное — серые полупрозрачные элементы «ещё не залито». Повторный поиск заменяет серые, отмеченные в захватках остаются.
- **Деления на стены и колонны на плане нет** — элементы просто куски конструкции, как льют (стены/колонны — только в объёмах).
  Длинную стену или плиту делят **«Ножницы / шов»**: провести поперёк — элемент делится; линия почти вдоль оси выпрямляется;
  шов остаётся на плане красным зигзагом.
- **Отметка захватки:** касание цветного квадратика у номера захватки в таблице (на размеченном листе) — режим «Захватка N —
  отмечайте элементы»: касание элемента — в захватку (окрашивается её цветом), повторное — снять, провести пальцем — все под
  ним; элемент из другой захватки переносится. Под пальцем и пером — **лупа с перекрестием**, элемент подсвечивается заранее,
  касание берёт ближайший (тонкая стена). Панель: «Захватка N · отмечено K · выполнено ≈ X %», «● Цвет», «Отменить» (шаг
  назад, режим остаётся), «Обвести вручную», «Готово».
- **Процент «выполнено ≈ X %»** — в шапке плана (и на сайте): площадь элементов в захватках к площади всех элементов,
  **примерно, без м²** (Владимир: «площадь не указывать — если приложение ошибётся, а кто-то возьмёт за эталон»). 100 % —
  «забетонировано ✓».
- **Цвета захваток:** каждой новой — свой заметно другой цвет (12 привычных, дальше оттенки «золотым углом»); «● Цвет» —
  палитра, **«Любой цвет»** (оттенок, насыщенность, яркость) и пипетка.
- **Лупа** — во всех режимах работы с планом, пальцем и пером (кроме кисти); привязка к углам — только «По точкам», «▭», «◯».
- **Привязка как в AutoCAD** (0.26.1, Владимир: «навожусь на угол — он привязывает»): если у листа есть PDF, точка сама встаёт в
  угол или конец линии чертежа (зелёный квадрат, под лупой «угол») или в пересечение линий (квадрат с крестом, «пересечение»).
  Размеры, оси, текст и штриховка не привязывают. Лист без PDF (вставлен до 0.26 или картинкой) — привязка только к своим точкам и
  углам областей; «Элементы ▾ → Выбрать тот же PDF» включает и её.

## 9. Сводка и контроль
Где считать: вся доска / раздел / одна таблица. Как лист «Статистика» в Excel:
- всего схем, **сдано в ПТО / не сдано**;
- по статусам ИГС × по шифрам; по исполнителям (подрядчикам);
- Чек-лист и DWG по статусам;
- открытые ведомости: сколько схем ждут ответа и сколько дней.

**Контроль** (касание — переход к строке):
- чек-лист предъявлен, а ИГС «Не предоставлена»;
- ИГС «В работе» и дальше, а чек-лист не «Предъявлено»;
- «На подписи у заказчика» и «На согласовании АН» дольше срока — **срок настраивается** (сначала 7 дней); такие схемы
  помечаются и в таблице.

«Скопировать для Excel» — сводка таблицей.

### 9.1. Выгрузка в Excel
- Кнопка «Выгрузить в Excel» → файл `.xlsx` → отправить (почта, мессенджер) или сохранить.
- **Отбор перед выгрузкой:** всё или только нужное — по статусам ИГС, Чек-листа, DWG, по шифрам, по подрядчикам,
  по разделу (можно сочетать: «КЖ 6.1.1 и КЖ 6.1.2, подрядчик АР-Старт, всё кроме „Сдано в ПТО“»).
- В книге: лист «Сводка» (как «Статистика»), лист «Схемы» (все отобранные строки, столбцы как в таблицах, с фильтром
  в заголовке) и по листу на каждый шифр (как сейчас в Excel Владимира).
- Ведомость тоже выгружается отдельно — как опись для заказчика.

## 10. Совместная работа и доступ
- Около 10 человек на объекте: **геодезисты правят, ПТО смотрит**.
- Доступ — как сейчас: **код на правку** (геодезистам) и **код «только смотреть»** (ПТО).
- Имя и фамилия обязательны для правок (в приложении уже есть; на сайте спросить один раз) — нужно для истории.
- **Правка с компьютера** через сайт (по коду на правку): таблицы, ведомости, статусы.
- iPhone и компьютер — через сайт; отдельного приложения для iOS нет.

## 11. Как это устроено (для разработчика)
- Всё хранится в доске, как остальные предметы: **таблица**, **схема** (строка), **ведомость**, **позиция ведомости**,
  **событие истории** — каждая отдельным предметом со своим номером. Поэтому правки разных строк не конфликтуют,
  а история только дописывается.
- Таблица хранит только место, размер, шифр и столбцы; строки знают свою таблицу и порядок в ней. Ведомость хранит ссылки
  на схемы (без копий), её позиции — результат и дату ответа; исходный состав — в самой ведомости.
- Сервер тот же (функция Яндекс Облака + база YDB): новые виды предметов он принимает без доработки.
  Объём: тысячи схем и событий — единицы мегабайт, в бесплатный лимит (1 ГБ) укладывается с большим запасом.
- Старым версиям приложения таблицы не видны («вид из будущей версии») — всем обновиться.

## 13. Не делаем сейчас
- Загрузку файлов (DWG, PDF, сканы) — не грузим сервер.
- Роли и тонкие права — хватает кодов «правка» / «только смотреть».
- Перекраску заливок на доске по статусу — Владимир смотрит статусы в таблице (на плане под таблицей — переключатель, раздел 8а).
- Загрузку текущего Excel — таблица Владимира ещё не готова.

## 14. Интерфейс: телефон, планшет, компьютер

**Требование Владимира: удобно работать и с обычного телефона, и с планшета, и с компьютера. Дело не в размере экрана —
доска бесконечная, её приближают и отдаляют, — а в удобстве ввода и пользования.**

### 14.1. Одна доска везде
- Рабочее место на всех устройствах одно — **доска**: чертежи, таблицы ИД рядом с ними, ведомости. Её двигают и
  приближают как сейчас (два пальца, колесо мыши).
- Сводка, архив ведомостей, поиск — **панели поверх доски** (на телефоне выезжают снизу, на планшете и компьютере — сбоку),
  доска под ними остаётся.
- Поиск: «КЖ 6.1.2 7 бетон» → список найденных строк → касание — доска переезжает к строке и подсвечивает её.

### 14.2. Ввод на телефоне — пальцем
- Палец не обязан попадать в маленькую ячейку: **касание любой части строки открывает снизу карточку строки** — все поля
  крупно: три статуса (ИГС, Чек-лист, DWG) большими цветными кнопками, даты, текстовые поля. Править можно, не приближая доску.
- Смена статуса — касание кнопки статуса в карточке → список крупных кнопок → выбор (**2 касания**).
- Кнопки «▲ / ▼» в карточке — к соседней строке, карточка не закрывается: можно пройти всю таблицу подряд.
- Текст — клавиатура телефона с подсказками из уже введённого в этом столбце; частые значения — кнопками.

### 14.3. Ввод на планшете — пером
- **Писать прямо в ячейку пером**: написал «4.1» в ячейке «Захватка» — распознаётся и встаёт текстом (как «В текст»).
- **Активная ячейка** (0.20.1, просьба Владимира: «писать где угодно, а текст сам в строку встаёт»): касание пером ячейки
  в «В текст» — она подсвечена, дальше пишут в любом месте экрана — текст в неё; «→» — следующая ячейка, «↓» — строка ниже,
  «Готово» или касание мимо таблиц — снять.
- Касание статуса пером → список рядом с ячейкой → выбор.
- Обвести несколько строк (лассо) → действия для всех: статус, в ведомость, «Конструкция не выполнена».
- Ладонь не мешает (защита от ладони уже есть). Пальцем — двигать доску и открывать карточку строки, как на телефоне.

### 14.4. Ввод на компьютере — мышь и клавиатура
- Клик по ячейке — печатать сразу; **Tab / Enter / стрелки** — к следующей ячейке и строке, как в Excel.
- Статус — выпадающий список у ячейки; цифры **1–8** — статус по номеру.
- **Вставка из Excel** (Ctrl+V): скопировали несколько строк в Excel — вставились строками таблицы.
- Выделение строк мышью (Shift / Ctrl) → действия для всех. Ctrl+Z — отменить.

### 14.5. Ускорители ввода (на всех устройствах)
- Подсказки из уже введённого (конструкции, подрядчики, виды работ).
- «+ Следующая захватка»: номер +1, конструкция и подрядчик как у предыдущей.
- Несколько видов работ за раз: отметил «Опалубка» + «Бетон» → две строки.
- Массовая смена статуса у выделенных строк; «Конструкция не выполнена» одной кнопкой.
- Ведомость собирается отбором («все „В работе“ по КЖ 6.1.1») или выделением строк на доске; позже — номера пером списком.
- «Отменить» последнее действие везде.

### 14.6. Общие правила
- Крупные кнопки в карточках и списках — не меньше 48 dp (работа на объекте, на ходу).
- Статус всегда **цвет + текст**; светлая контрастная тема — читается на улице.
- Одинаковые названия, цвета и порядок кнопок на всех устройствах.
- Приложение работает без интернета, правки уходят при появлении связи; сайт показывает «нет связи».

### 14.7. Как проверим дизайн до кода
Кликабельный макет: доска с чертежом и таблицей (двигать, приближать), карточка строки, смена статусов, ведомость с
ответами по частям, сводка, поиск, выгрузка. Открывается на телефоне, планшете и компьютере и подстраивает способ ввода.
Ввод пером в макете показывается подсказкой (в браузере перо не распознаётся) — проверяется уже в приложении.

## 15. Решения Владимира

Ответы на первые вопросы (11.11.2026):
1. Одна строка — одна схема; если на работу несколько схем, её дробят на захватки/участки.
2. Таблица настраиваемая: бетон делится на захватки по этажу, лотки — участки со своей нумерацией; на этом объекте этаж и
   секция определяются шифром, на другом могут понадобиться отдельные столбцы.

6. Файлы не загружать (нагрузка на сервер); Чек-лист и DWG — статусы.
7. ~10 человек: геодезисты правят, ПТО смотрит; правка с компьютера тоже нужна.
8. Одна доска — один объект; на ней разделы: монолитный каркас, кладка, сети, благоустройство.
9. Захватки раскрашиваются разными цветами для ориентира; статусы — в таблице; нужна связь заливки со строками таблицы

10. Excel пока не загружать — таблица ещё не готова.
