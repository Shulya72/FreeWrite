# FreeWrite — ТЗ и план развития

Версия плана 3 от 08.11.2026 (2-я — 07.11.2026). Основа — пожелания Владимира (чат 07.11.2026), его ответы на вопросы
(раздел 5) и обзор лучших приложений-досок и строительных приложений (источники — в конце).
План идёт шагами: каждый шаг — готовый APK, проверка на планшете, и только потом следующий шаг.

**Что изменилось во 2-й версии (по ответам Владимира):** чертежи — картинки JPG; захватки Владимир
раскрашивает сам (маркером или залитой фигурой поверх стены) — автоматическая раскраска по датам не нужна;
статусы — свой настраиваемый список; номера, даты и шифры пишутся от руки; замеры не нужны;
пользователей около 10 одновременно (Android и компьютеры); **всё должно быть бесплатным** — приложение
для себя, не на продажу.

**Что изменилось в 3-й версии (08.11.2026):** общая доска через сервер в Яндекс Облаке уже работает
(0.10, проверено с коллегой), телефон без пера — 0.11. Сделанное по версиям — раздел 6,
**очередь — раздел 7**. Сайт для компьютера (просмотр из Питера) — после PDF и остатка шага 3.

## 1. Для чего это всё

**Блокнот вместо бумажного ежедневника.** Пришёл на совещание, открыл планшет, пишешь пером в любом месте.
Рукопись становится текстом, задачи отмечаются «сдано / не сдано». ИИ помогает: пересказывает,
выписывает задачи и оформляет записи.

**Доска стройки.** На стройке много конструкций, и доска нужна, чтобы видеть всё целиком.

- На доску закидываются чертежи всех проектов.
- Захватки раскрашиваются по датам бетонирования.
- Для каждой захватки видно, есть ли исполнительная геодезическая схема (ИГС) и в каком она состоянии.

Работают с доской трое:

| Кто | Чем пользуется | Что делает |
|---|---|---|
| Владимир | Планшет MatePad Mini, перо | Ведёт доску: чертежи, захватки, статусы, надписи, стрелки, выноски |
| Второй геодезист | Обычный Android-телефон без пера, в поле | Открывает ту же доску, отмечает «так / не так», ставит статус, фотографирует, пишет комментарий |
| Руководство в Санкт-Петербурге | Компьютер, браузер | Смотрит, в какой стадии что находится: раскраска, фильтры, сводка. Ничего не устанавливает |

## 2. Что умеют лучшие приложения и что из этого берём

| Приложение | Чем сильно | Что берём в FreeWrite |
|---|---|---|
| **Miro** | Бесконечная доска, фреймы-разделы со своей ссылкой, стрелки-соединители между объектами, стикеры, теги, комментарии к объекту, ссылка «только просмотр» | Фреймы-разделы (по объектам и секциям), стрелки, «прилипающие» к объектам, комментарии, доступ «только просмотр» для руководства |
| **Apple Freeform / Microsoft Whiteboard** | Бесконечное поле, фото и PDF прямо на доске, перо, совместная работа | Чертежи PDF на доске, совместная работа |
| **Goodnotes / Samsung Notes** | Лассо (выделить и переместить рукопись), ровные фигуры («нарисуй и задержи перо»), распознавание рукописи | Лассо, ровные фигуры (уже есть «Фигуры»), «задержи перо — ровная линия» |
| **Concepts** | Бесконечное векторное поле, слои, точные инструменты | Слои: «чертежи» отдельно, «разметка» отдельно, чтобы случайно не сдвинуть чертёж |
| **tldraw / Excalidraw** | Стрелки, привязанные к фигурам (фигуру двигаешь — стрелка тянется). Тысячи объектов без тормозов: рисуется только видимое, поиск объектов по пространственному индексу | Привязанные стрелки и выноски; способ быстрой отрисовки (см. шаг 2) |
| **Fieldwire** (стройка) | Листы чертежей с версиями. «Пины» задач на чертеже со статусом, фото, чек-листом, исполнителем. Облака, стрелки, текст. Калибровка масштаба и замеры на чертеже | Захватка как объект со статусом, фото и историей. Версии листов. Позже — масштаб и замеры |
| **Bluebeam Revu** (стройка) | Разметка PDF, замеры, сравнение версий чертежей, совместные сессии | Сравнение версий чертежа (позже), совместная разметка |
| **PlanRadar, Project Point, Adept: Стройконтроль** | Замечания и дефекты прямо на плане объекта, фото, статусы | Отметки «так / не так» с фото с телефона в поле |

**Чем FreeWrite будет отличаться от них:**

- рукописный ввод на русском и ровные фигуры пером;
- доска стройки с захватками, датами бетонирования и статусами ИГС — готовыми, без настройки;
- работает без интернета;
- сервер в России — работает без VPN, оплата в рублях.

## 3. Общие правила

1. **Без интернета работает всё, кроме ИИ и обмена.** Изменения копятся в телефоне и уходят, когда появится сеть.
2. **Планшет с пером — главное устройство.**
   - Телефон без пера — полноценный помощник для поля: статусы, фото, комментарии, рисование пальцем.
   - Компьютер — просмотр через браузер.
3. **Данные и сервер — в России (Яндекс Облако).** Зарубежные сервисы бывают недоступны без VPN.
   **Бесплатно:** укладываемся в бесплатные лимиты сервисов, платных тарифов не подключаем.
4. **Каждый шаг заканчивается APK и проверкой на планшете.** Только потом следующий шаг.
5. **Главный приоритет — качество распознавания русского почерка.** Ничего не должно его ухудшать.

Всё, что Владимир попросил напрямую:

| Что | Как должно работать |
|---|---|
| Название при создании | «Новая запись» / «Новая доска» сразу спрашивают название (предлагается «Запись 7 ноября»). Можно стереть и написать своё |
| Больше цветов | Кнопка «Цвет» открывает палитру из 24 цветов (тёмные, яркие, бледные — для заливок). Последний выбранный «свой» цвет запоминается |
| Пипетка | В палитре — «Пипетка». Наводишь перо: в кружке виден цвет под пером. Касаешься объекта (надписи, штриха, фото, метки) — цвет становится таким же |
| Правка надписей на доске | Палец по надписи — она выделена. Тянуть — передвинуть, уголок — больше/меньше. Кнопки «Изменить» (поправить текст), «Копия», «Цвет», «Удалить» |
| Выделение любых объектов | Инструмент «Выделить» вместо «Руки»: обвести пером (лассо) несколько объектов — двигать, увеличивать, копировать, перекрашивать, удалять разом. Касание пальцем — выделить один |
| Стрелка — объект | Стрелку (и любую фигуру) выделяешь, двигаешь, тянешь за уголок, копируешь |
| Кривые стрелки | Дуга, волна или сплайн с наконечником на конце — становится плавной стрелкой с ровным наконечником по направлению линии |

**Готово, когда на планшете:**

- название спрашивается;
- пипетка берёт цвет с фото и с надписи;
- надпись после распознавания двигается, растягивается и копируется;
- дуга со стрелкой становится ровной дугой-стрелкой;
- лассо выделяет несколько объектов.

### Шаг 2 — версия 0.8 «Быстрая доска» (производительность) — выпущена 07.11.2026, ждёт проверки на планшете

**Сделано в 0.8.0.** Замеры на компьютере сборки на доске из 120 чертежей и 5 320 объектов
(планшет медленнее в несколько раз, но соотношения те же):

| Что | Было (0.7) | Стало (0.8) |
|---|---|---|
| «Отменить» — запомнить доску после каждого действия | 75 мс | 2 мс |
| Кадр, когда видна вся доска | 133 мс | 28 мс |
| Кадр во время письма пером | как вся доска | 2,5 мс |
| Кадр при приближении | 36 мс | 17 мс (рисуется 71 объект из 5 320) |
| Сохранение | 171 мс прямо во время работы | 8 мс подготовка, запись в фоне |
| Список досок в Ежедневнике | 107 мс | 5 мс |

Картинки: оригинал до 8192 px (JPEG без пережатия) + копии 256/1024/2048 px, загрузка в фоне,
память ограничена, при сильном приближении — чёткий кусок оригинала. На планшете — «Проверка планшета →
6. Скорость доски → Создать тестовую доску» (500 чертежей, 5 000 штрихов, 1 000 надписей…); внизу слева на
доске видно мс на кадр (подержать — скрыть/показать). SQLite не понадобился: хватило записи по частям
с готовыми строками.

**Цель:**

- на доске 500 чертежей и фото и 5 000 надписей и штрихов;
- сдвиг и масштаб плавные (60 кадров в секунду на MatePad Mini);
- доска открывается быстрее 2 секунд;
- сохранение незаметно.

**Как добиться:**

- **Рисовать только видимое.** Объекты ищутся по «карте участков» (пространственный индекс). Невидимые не рисуются вообще: из 5 000 на экране обычно 50–200.
- **Картинки в нескольких размерах:**
  - маленькая копия — для общего вида;
  - средняя — для обычного масштаба;
  - большой чертёж при сильном приближении грузится кусками (плитками), только видимые куски.
- **Картинки грузятся в фоне.** Пока картинка грузится, на её месте видна маленькая копия, а не пустота. Память ограничена: давно не видимые картинки выгружаются.
- **Слой надписей и штрихов** во время сдвига рисуется готовой картинкой, а не заново каждый кадр.
- **Хранение — база (SQLite), а не один большой файл.** Сохраняется только изменённое.
- **«Отменить» хранит действия** («сдвинул объект 17»), а не копию всей доски.
- **Тестовая доска-генератор** (500 картинок, 5 000 объектов) и замер скорости. Цифры — в отчёт перед выпуском.

**Готово, когда:** тестовая доска на планшете двигается без рывков и открывается за 2 секунды.

### Шаг 3 — «Чертежи, заливки и статусы» (основное — в 0.7.0)

**Сделано в 0.7.0:** пачка картинок из галереи, «Заливка», «Залить» для замкнутой фигуры, свой список статусов
(добавить, переименовать, перекрасить, порядок, удалить), метка: касание — следующий статус, удержание —
список; **мультивыноска-статус**: верхняя строка — надпись («Захватка №1 от 11.09.26»), нижняя — кнопка
статуса цветом статуса, касание — следующий по списку («Сдали опалубку» → «Забетонировано» → «Сняли
опалубку» → …), несколько указателей со стрелками. **PDF → картинки — в 0.12.0.** **Осталось:** подсветка
одного статуса из легенды, привязанные стрелки, фреймы-разделы.

| Что | Как должно работать |
|---|---|
| Чертежи JPG | «Картинка» берёт сразу много картинок из галереи и раскладывает их по доске рядами. Большой чертёж остаётся чётким при сильном приближении |
| PDF — по желанию | Если проект пришёл в PDF, приложение само превратит страницы в картинки (Android это умеет без сторонних программ). DWG не открываем: из AutoCAD его сохраняют в PDF или JPG |
| Заливка (захватки) | Инструмент «Заливка»: обвести пером захватку поверх стены — получается залитая область выбранного цвета, полупрозрачная, чертёж под ней виден. Замкнутую фигуру из «Фигур» тоже можно залить. Цвет и прозрачность заливки меняются через выделение. Маркер — как сейчас |
| Свои статусы | У доски свой список статусов: «Добавить статус» — название и цвет. Можно переименовать, перекрасить, удалить. По умолчанию — «Нет схемы / В работе / На проверке / Сдана / Замечания» |
| Метка статуса | Ставится пером, как сейчас. Касание метки — выпадающий список статусов доски, выбираешь нужный (вместо перебора по кругу) |
| Легенда и фильтр | Панель «Статусы»: каждый статус с цветом и числом меток. Касание статуса — подсветить только его метки, остальное притушить |
| Номера, даты, шифры | Пишутся от руки («В текст»), отдельных полей не делаем |
| Мультивыноска | Один текст и несколько линий-указателей со стрелками или точками к разным местам. Текст двигаешь — линии тянутся. Концы прилипают к объектам |
| Привязанные стрелки | Стрелка от объекта к объекту остаётся привязанной, когда объекты двигают |
| Фреймы-разделы | Рамка «Секция 3», «Корпус 1» с названием. Список разделов — быстрый переход. Чертёж внутри можно «закрепить», чтобы не сдвинуть случайно |

**Готово, когда:**

- реальные чертежи Владимира (JPG) загружены на доску пачкой;
- захватки залиты цветом поверх стен, чертёж под заливкой виден;
- свой статус добавлен и выбран из списка на метке;
- легенда считает метки и подсвечивает один статус;
- выноска указывает на несколько захваток.

### Шаг 4 — версия 0.9 «Общая доска» (синхронизация и доступ)

**Промежуточный вариант (раньше сервера) — сделан в 0.9.0.** Кнопка «Поделиться» собирает файл `.freewrite` (целиком с картинками или только правки и новые картинки). Файл отправляется в мессенджер, коллега открывает его в своём FreeWrite: новая доска добавляется, знакомая — правки сливаются по каждому предмету (поздняя правка побеждает, удаления доходят, старый файл ничего не портит). У каждого предмета уже есть номер и отметка правки — сервер будет пересылать те же записи, только сам и сразу.

**Полный вариант:**

| Что | Как |
|---|---|
| Вход | По приглашению: ссылка или код. Аккаунт — телефон или почта |
| Роли | Владелец; редактор; «поле» (статусы, отметки, фото, комментарии, без права двигать чертежи); зритель (только смотреть) |
| Синхронизация | У каждого объекта свой номер и версия. Изменения — короткие записи («статус захватки 12 = сдана»). Без сети копятся, при сети уходят на сервер и приходят коллегам за секунды |
| Конфликты | Правки разных объектов друг другу не мешают. Если двое поменяли одно поле одного объекта, остаётся последняя правка, а в истории видны обе |
| История | Кто, что и когда изменил. Можно вернуть прежнее |
| Сервер | Яндекс Облако: хранилище файлов (чертежи, фото), база объектов, небольшая серверная программа для входа, доступа и рассылки изменений |
| Стоимость | **Бесплатно** — в пределах бесплатных лимитов Яндекс Облака (см. ниже) |

**Как уложиться в бесплатные лимиты на 10 человек.** Каждый месяц Яндекс Облако не берёт денег за:

- первый 1 млн вызовов серверных функций;
- 1 ГБ базы и 1 млн операций с ней;
- 1 ГБ хранилища файлов и 100 ГБ скачиваний.

Что для этого делает приложение:

- **Сжимает картинки при загрузке на сервер** (чертёж — до 2048 точек, около 0,5 МБ; фото с телефона — около 0,3 МБ). В 1 ГБ помещается примерно 1 500–2 000 картинок.
- **Отправляет только изменения** — короткие записи, а не всю доску.
- **Спрашивает сервер о новостях раз в 10–15 секунд и только пока приложение открыто.** 10 человек по 8 часов в рабочие дни — около 400 тысяч вызовов в месяц, это меньше бесплатного миллиона.
- **Показывает, сколько места занято**, и предупреждает заранее, если близко к лимиту.

Чтобы завести облако, скорее всего, придётся привязать банковскую карту к платёжному аккаунту Яндекс Облака. В пределах бесплатных лимитов деньги не списываются, но мы ещё поставим уведомление о любых расходах. Если карта не подходит, запасной вариант — бесплатный тариф Cloudflare: там лимиты больше (10 ГБ файлов), но из России он временами работает с перебоями. Окончательно выбираем на шаге 4.

**Готово, когда:**

- две копии приложения (планшет и телефон) видят изменения друг друга;
- статус, поставленный на телефоне без сети, доходит до планшета, когда сеть появилась;
- за месяц работы расход в облаке — 0 ₽.

### Шаг 5 — версия 1.0 «Телефон и браузер»

**Телефон без пера — режим «Поле»:**

- крупные кнопки, всё делается пальцем;
- касание метки — список статусов доски, «Фото» (камера, снимок сразу привязан к метке), комментарий;
- отметки «так / не так» на чертеже;
- работает офлайн.

**Браузер для Санкт-Петербурга:**

- ссылка на доску, ничего не нужно устанавливать;
- доску можно двигать и масштабировать;
- легенда статусов с числами, подсветка одного статуса;
- фото, привязанные к меткам;
- доступ «только просмотр», позже — комментарии;
- сайт лежит в том же бесплатном хранилище Яндекс Облака.

**Готово, когда:**

- геодезист на своём телефоне ставит статус и фото в поле;
- руководство в браузере видит это без обновления страницы.

### Шаг 6 — версия 1.1 «ИИ-помощник»

| Где | Что делает ИИ |
|---|---|
| Блокнот | «Итоги»: краткий пересказ совещания, задачи со сроками и ответственными. «Оформить»: заголовки, списки, исправленные опечатки. Результат показывается заранее, его можно принять или отменить. Исходник не теряется |
| Распознавание | Для сомнительных слов ИИ выбирает по смыслу из вариантов, которые предлагает распознаватель. Учитывает строительные слова (захватка, ИГС, АОСР, опалубка, армирование) и личный словарь Владимира |
| Доска | Ответы на вопросы: «сколько меток „Нет схемы“ и где?». Сводка для руководства одним текстом |

**Какой ИИ.** Главный кандидат — GigaChat: у него есть бесплатный режим для частных лиц (объём бесплатных токенов уточним на шаге 6 по странице тарифов). YandexGPT — платный, его подключать не будем.

- ИИ запускается только по кнопке, поэтому бесплатного объёма должно хватать.
- Ключ хранится на сервере, не в приложении.
- Без интернета ИИ недоступен. Сам рукописный ввод работает без интернета, как сейчас.

**Готово, когда:** «Итоги» на реальной записи совещания дают внятный пересказ и список задач, а «Оформить» не искажает смысл.

## Для разработчика

- **Шаг 2.** Индекс: равномерная сетка ячеек или R-tree по рамкам объектов; запрос по рамке экрана.
  - Картинки: при импорте — копии 256 и 1024 px. Для полного размера — `BitmapRegionDecoder` по плиткам 512 px с учётом масштаба. LRU-кэш по байтам (около 1/4 доступной памяти). Декодирование — в фоновом пуле.
  - Штрихи: `Path` строится один раз на объект и пересчитывается только при изменении. При движении камеры — кэш слоя (`Picture`/`Bitmap`) с перерисовкой по окончании жеста.
  - Хранение: SQLite (`android.database.sqlite`, без Room — проект без AndroidX). Таблицы `objects(id, board, kind, z, bbox, data, version, updated)` и `assets(id, w, h, sha)`.
  - Отмена — стек операций. Сохранение — пакетами по изменённым объектам.
- **Шаг 3.** Заливка — новый вид объекта на доске: многоугольник с точками контура, цветом, прозрачностью (по умолчанию около 35 %) и линией по краю. Рисуется под надписями и метками, над картинками.
  - Статусы доски — список `{id, name, color}` в JSON доски. Метка хранит id статуса. Старые 0/1/2 переводятся в три статуса по умолчанию.
  - PDF — `android.graphics.pdf.PdfRenderer` (копия файла в кэш — у некоторых приложений поток без перемотки), страница на белом фоне → JPEG 90 с уровнями 256/1024/2048; большая сторона ~200 точек на дюйм, от 2048 до 4096 px (6144 на устройствах с запасом памяти).
- **Шаг 4.** Модель изменений — журнал операций над объектами. Каждый объект хранится как запись с полями, объединение по полю «последний пишет» с часами Лэмпорта (Hybrid Logical Clock), идентификатор — UUID.
  - Полноценный CRDT (Yjs/Automerge) нужен для совместного редактирования одного текста. Для полей объектов доски достаточно LWW по полю; решим на шаге 4 после замеров.
  - Файлы — по хешу (sha256) в Object Storage. Доставка изменений — опрос раз в 10–15 с, пока приложение открыто (укладывается в 1 млн бесплатных вызовов). Сервер — Cloud Functions + YDB serverless + Object Storage в бесплатных лимитах. Запас — Cloudflare Workers + Durable Objects + R2 (бесплатный тариф).
- **Шаг 5.** Веб-просмотрщик — та же модель объектов, отрисовка на Canvas в браузере. Простой статический сайт плюс API.
- **Шаг 6.** ИИ — через свой серверный слой (ключ не в APK). Запросы с контекстом записи. Ответы показываются как предложение (diff), применяются только по кнопке.
