# Заставка ViaDesk

Выбор Владимира (20.11.2026): вариант «Ночная стройка» — «оставляем надпись, логотип и город».

- `bg.html` — фоны (варианты A–G; в приложении — `v=E`), размеры экрана — `?w=…&h=…`; `&hero=1&nobld=1` — со знаком и
  надписью посередине (для просмотра).
- `hero.js` — знак и надпись векторно (по баннеру `../viadesk-banner.jpg`: те же места и размеры), шрифт надписи — Montserrat
  Bold из приложения, подпись — Inter. `hero_alpha.html` — знак и надпись без фона.
- Пересобрать картинки приложения (`app/src/main/res/drawable-nodpi/splash_*.webp`), из этой папки:
  `node render_e.js bg && node render_hero.js && python3 make_assets.py` (нужны Playwright с Chromium и Pillow).
  Снимки делаются в 4–6 раз крупнее экрана и уменьшаются — края гладкие.
- В приложении — `Splash.kt`: фон под форму экрана (планшет 1600×2560, телефон 1080×2340, набок 2560×1600) и знак с надписью
  поверх, посередине, 0,8 ширины.
